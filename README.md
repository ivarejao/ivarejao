## Featured projects (start here)

- **Vibdata** — a Python package providing a common interface to store/manipulate vibration datasets for ML in fault diagnosis  
  Repo: [ivarejao/vibdata](https://github.com/ivarejao/vibdata)  
  Highlights:
  - Unified interface + multiple public datasets
  - Modules for `raw` dataset handling and `deep` (deep-learning-friendly, incl. PyTorch-oriented workflows)
  - Paper-reproducibility tags (see README)

- **Similarity bias benchmarks (fault diagnosis)** — benchmark code and experiments for the “similarity bias” problem in vibration-based ML  
  Repo: [ivarejao/vibdata-baselines](https://github.com/ivarejao/vibdata-baselines)  
  Includes baselines like Nearest Neighbor, Random Forest, and a 1D CNN (XResNet18-1D), evaluated under multiple cross-validation strategies.
